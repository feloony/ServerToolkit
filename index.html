About ServerToolkit

ServerToolkit, created by VoxelHosting, is an open-source suite of powerful tools designed to streamline Minecraft server management. Instead of hunting down individual utilities for daily administrative tasks, server owners can manage everything seamlessly from one centralized website.

Every tool runs locally in your browser. No data is sent to external servers.
