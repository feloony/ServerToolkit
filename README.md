# ServerToolkit

A modern, open-source collection of tools for Minecraft server owners and developers.

## Tools

- **MOTD Generator** (`motd.html`) — Create and preview Minecraft MOTDs with colors and formatting.
- **Server Properties Editor** (`server-properties.html`) — Edit and validate `server.properties` locally.
- **Java Arguments Generator** (`java-arguments.html`) — Generate Java startup arguments based on server software and RAM.
- **Server Information** (`server-info.html`) — Query server status, version, and player count (API-ready).

## Getting Started

Open `index.html` in your browser. All tools run client-side and require no build step.

## Development

This is a static site. Edit the HTML, CSS, and JS files directly and refresh.
